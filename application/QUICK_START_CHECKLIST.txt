Follow these steps in order to run your application locally with the blogs feature.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ STEP 1: START MYSQL & APACHE (2 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

If using XAMPP:
  ☐ Open XAMPP Control Panel
  ☐ Click "Start" next to Apache
  ☐ Click "Start" next to MySQL
  ☐ Wait until both show GREEN "Running"

If using WAMP:
  ☐ Open WAMP
  ☐ Ensure all services are GREEN

If using other tools:
  ☐ Make sure MySQL service is running

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ STEP 2: CREATE DATABASE TABLE (2 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Open phpMyAdmin:
   ☐ Visit: http://localhost/phpmyadmin
   ☐ Login with: root / root

2. Select Database:
   ☐ Click on database: "u748543024_mastercraft"

3. Create Blogs Table:
   ☐ Click the "SQL" tab at top
   ☐ Open file: database/migration_blogs_table.sql
   ☐ Copy ALL the SQL code
   ☐ Paste into phpMyAdmin SQL box
   ☐ Click "Go" button
   ☐ Table "cr_blogs" should be created ✓

Option A: PHP Built-in Server (Easiest)

1. Open Command Prompt
   ☐ Press: Windows + R
   ☐ Type: cmd
   ☐ Press: Enter

2. Navigate to Project:
   ☐ Type: cd C:\Users\nitin\Downloads\application
   ☐ Press: Enter

3. Start Server:
   ☐ Type: php -S localhost:8000
   ☐ Press: Enter
   
   You should see:
   "Development Server started at http://127.0.0.1:8000"

4. Open Browser:
   ☐ Go to: http://localhost:8000

❌ TROUBLESHOOTING QUICK TIPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

"Server refused to connect"
→ Ensure MySQL and Apache are running (XAMPP Control Panel)
→ Ensure PHP server is started (should show green message)

"404 - Blogs not found"
→ Hard refresh: Ctrl+Shift+Delete (clear cache)
→ Check database table exists in phpMyAdmin
→ Restart PHP server: Ctrl+C then run php -S localhost:8000 again

"No blogs showing"
→ Check sample data SQL was executed
→ Run in phpMyAdmin: SELECT * FROM cr_blogs WHERE status = 1;
→ Should show 4 rows

"CSS/Images not loading"
→ Press Ctrl+Shift+R to hard refresh
→ Check browser console (F12) for errors

"Database connection error"
→ Check MySQL is running
→ Verify credentials in config/database.php
→ Try phpMyAdmin to test connection
